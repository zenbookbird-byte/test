Datakällor

Tankkollen kombinerar flera källor i en prioritetskedja: officiella listpriser från kedjornas hemsidor först, crowdsourcad data och branschstatistik som komplement, cachade värden som fallback.

Tier 1

Kedjornas listpriser

Direkt-scraping av Circle K, OKQ8, Preem, Shell, St1, Ingo, Tanka och Qstars officiella prissidor. Uppdateras varje timme.

8 källor · högsta tillförlitlighet
Tier 2

Crowdsourcade aggregator-sajter

Bensinpriser.nu, Bensinstation.nu och Bensinpris idag, där användare rapporterar in priser från pumpen. Bra för pump-rabatter och regionala variationer.

3 källor · medelhög tillförlitlighet
Tier 3

Branschstatistik

Drivkraft Sveriges veckorapport och SCB:s drivmedelsindex. Långsammare uppdatering men oberoende referenspris.

2 källor · officiell statistik
Tier 4

OpenStreetMap

Stationspositioner, adresser och öppettider hämtas från OpenStreetMap Overpass API. Uppdateras varje vecka.

© OpenStreetMap-bidragsgivare · ODbL

Datapipelinen körs som GitHub Actions varje timme för priser och varje vecka för stationsdata. Källkoden är öppen och tillgänglig för granskning. Priset vid pumpen kan avvika med några öre per station.
